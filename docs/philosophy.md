# Philosophy

>Experiments are not the goal. Understanding is.

QTLab is not designed to maximize profits.

QTLab is designed to maximize confidence in research.

Its purpose is to help researchers reject weak hypotheses before risking real capital.

The platform values:

- reproducibility
- statistical rigor
- transparency
- modularity
- scientific methodology

over:

- optimization
- curve fitting
- black-box automation

A successful backtest is not considered evidence that a strategy works.

It is merely one piece of evidence requiring further validation.

>Every study should be understandable by the researcher who wrote it two years later.

## Principles

Knowledge compounds. QTLab preserves not only results but also the reasoning that produced them, allowing future
research to build on past understanding instead of repeating it.

Every feature in QTLab must help researchers learn something they didn't know before.

When the model and reality disagree, change the model.

## Product Principles

1. Think before you compute.
The software should encourage better questions before faster answers.

2. Preserve reasoning.
If a decision was made, the reasoning behind it should be preserved whenever possible.

3. Guide, don't automate.
QTLab helps researchers make better decisions.
It does not make the decisions for them.

4. Reveal complexity gradually.
A beginner should never be overwhelmed.
An expert should never feel constrained.

5. Every feature must improve research.
Not coding.
Not infrastructure.
Research.

6. Evidence has priority over opinion.
If evidence contradicts expectations, QTLab should make that contradiction visible.

7. Leave a better researcher behind.
Every completed Study should improve the person conducting it.
